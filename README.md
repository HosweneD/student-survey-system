# Система опросов и голосований

## Назначение приложения

Приложение предназначено для проведения анонимных опросов и голосований среди студентов учебного заведения. Основная цель - сбор честной обратной связи и мнений по различным вопросам с гарантией анонимности респондентов и публикацией агрегированных результатов.

## Основные пользовательские сценарии

1. **Авторизация студента:** Вход в систему по учётным данным (например, номер студенческого билета или корпоративная почта).
2. **Просмотр доступных опросов:** Студент видит список активных голосований, в которых он еще не участвовал.
3. **Прохождение опроса:** Выбор одного или нескольких вариантов ответа.
4. **Обеспечение анонимности:** Система сохраняет факт голосования, но не связывает ответы с конкретным студентом.
5. **Публикация результатов:** Просмотр статистики по завершённым опросам.
