## Необходимые экраны (страницы)

1. **Экран авторизации (LoginPage):** Форма входа.
2. **Главный экран / Список опросов (SurveyListPage):** Карточки с доступными опросами и их статусами.
3. **Экран прохождения опроса (SurveyPage):** Вопросы и варианты ответов, кнопка отправки.
4. **Экран подтверждения (SuccessPage):** Сообщение об успешном прохождении с напоминанием об анонимности.
5. **Экран результатов (ResultsPage):** Визуализация данных после завершения опроса.

## Запуск проекта

```bash
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173
